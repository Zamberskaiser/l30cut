# Log de build - Leonardo - 2026-09-03

## Resumo

Rodada do `build-windows.bat` (versão 7) no Windows. O build web passou, a interface estática foi encontrada, mas a instalação do `tauri-cli` via Cargo falhou por causa da versão.

```

[ERRO] A instalacao falhou. Leia a mensagem acima para ver o motivo.

```

## Diagnóstico

O script tentou instalar o `tauri-cli` pelo Cargo com `--version 2`, mas o Cargo exige um semver completo, por exemplo `--version ^2.0.0`.

## Correção aplicada

- `build-windows.bat` versão 8: alterada a linha do `cargo install` para:
  ```
  cargo install tauri-cli --version ^2.0.0 --locked
  ```
- Criado este log para consulta futura.
